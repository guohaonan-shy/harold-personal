# 03 — WebGL 字符场(桌面增强)

**Blocked by**:01(消费它的预生成字符矩阵)、02(settle 动画挂进分镜 800ms 触发槽位)
**设计冻结**:已冻结(spec [[home-motion-upgrade]] §4 的字符场口味,关键参数下方已内联)

## 要建什么

细指针(桌面)访客的 ASCII 头像卡片从静态升级为**活的字符场**:入场时字符从噪声 settle 成头像;鼠标划过时半径内字符快速轮换、被轻微推开、点亮为终端绿;hover 整卡时字符层渐隐、露出常驻底层的真实照片,移开恢复。

具体决策(来源 spec §4):

- **实现介质**:WebGL,库取 three.js 或 OGL 中**更轻者**(以打包体积为准,二选一)。这是全站唯一的 WebGL 表面——不加全页 shader、不做第二个 canvas 场景。shader 只渲染字符矩阵这一种"终端世界存在之物"。
- **入场**:settle 动画挂在 02 分镜预留的 800ms 触发槽位上,不自己另起触发时机;挂上后 boot 总时长仍须 ≤1.5s。
- **扰动口味**:鼠标半径内字符快速轮换(与既有字符解密动效同族的乱码感)+ 轻微斥力,**不做**夸张物理弹跳。半径内字符与全场最亮约 10% 的字符用终端绿,其余走 text 色阶——绿色只标记"活的"。
- **解密交互**:照片常驻字符层底下;hover 整卡 → 字符层渐隐;移开 → 恢复。不用 click 切换(桌面);01 的点按切换行为在细指针设备上由 hover 取代。
- **降级链**(全部维持 01 的静态形态 + tap/click 切换):粗指针设备**不创建 WebGL 上下文**;WebGL 不可用同样回退;reduced-motion 下无 settle、无扰动,直达稳定终态。
- **亮色主题**:深色字符、可辨认,无白底 glow——发光类效果在亮色下换成对比/字重差异。
- **性能**:消费 01 的预生成矩阵,运行时不重算图像;字符场不在视口时不做无谓渲染。

## 验收标准

- [x] 细指针:入场 settle、鼠标扰动 + 绿色点亮、hover 解密、移开恢复,四个行为全部可演示
- [x] settle 挂进 800ms 槽位后,boot 全程仍 ≤1.5s
- [x] 粗指针视口:页面不创建 WebGL 上下文,静态 ASCII + tap 切换保持 01 的行为
- [x] reduced-motion:无 settle、无扰动,卡片呈稳定终态
- [x] 亮色主题:字符为深色、头像可辨认、无发光效果
- [x] 滚动帧率相对改动前无明显退化;卡片滚出视口后渲染停止
- [x] 依赖清单仅新增一个 WebGL 库;构建与 lint 通过
