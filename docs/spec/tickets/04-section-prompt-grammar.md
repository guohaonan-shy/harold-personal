# 04 — Section 入场语法统一

**Blocked by**:无——可立即开工(与 01 并行 frontier;不碰 Hero,那是 02 的地盘)
**设计冻结**:已冻结(不新增视觉,只改动效时序;参数来源 spec [[home-motion-upgrade]] §4)

## 要建什么

首页各 section(项目、开源、经历、进行中、社交)获得统一的会话节奏:**prompt 行先打完,内容才入场**——像终端里命令回车后输出才出现,而不是现在标题和内容同时各自动画。

现状(已探明,写给没见过这个仓库的会话):所有 section 已共用同一个打字机标题组件,且已实现「进入视口触发、只播一次」——这两个行为**保持不动**。本刀补三件事:

- **完成信号**:打字机标题打完后对外发出完成通知(回调/事件均可,行为上等价即可)。
- **触发链**:各 section 内容的入场动画(既有的 0.6s easeOut 淡入上移参数**不变**)改为在完成信号之后开始,并保持内部 stagger;不再与标题同时开动。
- **速度与无障碍**:打字速度统一为 ~30ms/字符(现为 40ms);reduced-motion 下打字与内容入场动画全部跳过,标题完整显示、内容直接就位。

边界:只动**时序与触发关系**,不动任何 section 的布局、配色、文案;Hero 不碰。

## 验收标准

- [x] 逐个滚动到每个 section:标题打完后内容才开始入场,先后肉眼可辨
- [x] 打字速度 ~30ms/字符
- [x] 回滚再进入任一 section:prompt 不重播(既有行为未回归)
- [x] reduced-motion:所有标题完整显示无打字过程,内容无入场动画
- [x] 各 section 的终态视觉与改动前逐像素一致(只动时序,不动样子)
- [x] 构建与 lint 通过
